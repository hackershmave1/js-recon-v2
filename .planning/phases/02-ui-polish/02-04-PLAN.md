Step D2 — Add a helper method to the Dashboard class in dashboard.js. Insert the following method directly after the `showAlert` method definition (i.e., after its closing `}`):

```javascript
    showConfirm(message, okLabel = 'Delete') {
        return new Promise((resolve) => {
            const modalEl = document.getElementById('confirmModal');
            const bodyEl  = document.getElementById('confirmModalBody');
            const okBtn   = document.getElementById('confirmModalOk');
            const cancelBtn = document.getElementById('confirmModalCancel');
            if (!modalEl) { resolve(window.confirm(message)); return; }
            bodyEl.textContent = message;
            okBtn.textContent  = okLabel;
            const modal = bootstrap.Modal.getOrCreateInstance(modalEl);
            const onOk = () => { cleanup(); resolve(true); };
            const onCancel = () => { cleanup(); resolve(false); };
            const onHide = () => { cleanup(); resolve(false); };
            function cleanup() {
                okBtn.removeEventListener('click', onOk);
                cancelBtn.removeEventListener('click', onCancel);
                modalEl.removeEventListener('hidden.bs.modal', onHide);
                modal.hide();
            }
            okBtn.addEventListener('click', onOk);
            cancelBtn.addEventListener('click', onCancel);
            modalEl.addEventListener('hidden.bs.modal', onHide, { once: true });
            modal.show();
        });
    }
```

--- B. Remove uppercase text-transform override from card-header headings (dashboard.css ~lines 185-190) ---
Find the rule block:
  .card-header h5, .card-header h6 {
    font-size: 0.8125rem;
    font-weight: 600;
    text-transform: uppercase;
    letter-spacing: 0.06em;
    color: var(--text-secondary);
    margin: 0;
  }
Remove only the `text-transform: uppercase;` line. Leave all other declarations (font-size, font-weight, letter-spacing, color, margin) intact.

Removing uppercase lets the heading render with the case written in HTML, which the author controls.
Note: `letter-spacing: 0.06em` is intentional design (it accompanies the caps style), but retaining it after removing uppercase is acceptable — it creates a slightly tracked normal-case label, which is still readable and avoids a regression.
